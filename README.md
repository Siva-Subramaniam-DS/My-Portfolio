## ⚙️ Repository Structure & Setup

This portfolio is built using **React**, **Vite**, **GSAP animations**, and a dynamic multiple-theme framework.

### **Directory Structure**
```bash
├── public/                 # Static assets (favicons, background audio)
├── src/
│   ├── assets/             # Original raw media, logos, and images
│   ├── components/         # Reusable React UI components
│   ├── context/            # Global context (Dynamic Theme Provider)
│   ├── hooks/              # Custom React hooks (useGSAP, useTypewriter)
│   ├── utils/              # Helper modules (sound engine, image resolvers)
│   ├── App.jsx             # Core Application entrypoint
│   └── main.jsx            # React virtual DOM bootstrap
├── vite.config.js          # Vite compilation config
└── README.md               # Professional developer profile readme
```

### **Getting Started**

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Siva-Subramaniam-DS/Live-Portfolio.git
   cd Profolio-main
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
